## Overview ##

Welcome to lesson three. After completing the last lesson we know a little more about Glue and how Athena can be used to create Glue Tables. In this lesson we will explore another way in which we can manage data catalogs. In the latest version of Splunk Federated Search for Amazon S3 we can now get Splunk to managed a catalog on your behalf. This will help take the 'SH' (Splunk Joke) out of doing it yourself. For this lesson will explore how we configure Splunk managed catalog against logs from AWS Web Application Firewall (WAF).  

After this lesson you will get an understanding of the following:

1. **AWS WAF Logs**: Their structure and layout in Amazon S3

2. Understand how how to configure a Splunk managed catalog for your data. 

3. **Create our third Federated Search Dataset**: Using the Splunk managed catalog settings..
