# Workshop Welcome

![image_tag](/static/data-fabric-macgyver-logo.png)

Welcome to the Cisco Data Fabric MacGyver workshop! This workshop is designed to get you hands on with some of the concepts behind the Cisco Data Fabric architecture. This architecture is powered by the Splunk platform. 

The workshop was written by T-REX. Our friendly dinosaur who loves getting under the covers of different topics. 

To start us off its key to understand quickly, T-REX's three pillars of the Cisco Data Fabric. These are:

**Pillar One: Data Streaming**

The data streaming pillar of Splunk's, Cisco Data Fabric is all of the technology pieces which help you make and manipulate data at the source. We cannot do it justice here but some of these are 
* Edge and Ingest Processor, our data manipulation tools which help you redact, route and manipulate data to where and how you want it. 
* Our AI powered data onboarding tools which help you use the power of AI to onboards data a agentic speed! 

**Pillar Two: Data Storage**

The data storage tier of TREX's pillars of Cisco Data Fabric is all about what options we have when it comes to storing and landing data. They key behind this is to give you the choice. Choice, that makes sense based on your technology roadmap and requirements. Eg Splunk, Amazon, Azure, Snoflake, the list goes on. But don't forget, choice also allows you to optimise cost and performance as well. Now that's flexibility!

**Pillar Three: Data Analysis**

Now this pillar can be complicated once you get into it but basically Splunk and the Cisco Data Fabric has you covered. This is how you can analyse your data at ludicrous scale and searching it from no matter where it lives. You can using native build in options like SPL our AI agents or use the modern MCP connectivity and build your own! 

So as you can see the Cisco Data Fabric powered by Splunk is flexible technology architecture that allows you to get insights out of your data from anywhere at ludicrous scale at the performance and price so you don't have to make the choice on which data I would like to analyse. 

Alright, so now we know a bit about Cisco Data Fabric. Let's talk about what we have in store for you in the workshop labs.
